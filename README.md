## Selected projects

This portfolio contains selected projects from my professional and engineering experience. Most of the projects were developed as part of R&D and medical-device development.

The descriptions focus on my **role, responsibilities, technical challenges, and implemented solutions**. Due to the nature of the projects, source code, internal documentation, proprietary protocols, schematics, and confidential technical information are not included.

### Glucometer Communication Integration

Development of embedded communication support for multiple blood glucose meters.

The project involved investigating undocumented communication protocols, analyzing USB traffic, reverse engineering communication frames, implementing protocol support on a microcontroller, and testing communication with multiple devices.

**Focus:** C, SAMD21, USB, UART, protocol analysis, reverse engineering, embedded firmware, osciloskop.

### Universal HMI System

Development of an embedded control and user-interface system based on Raspberry Pi for three devices. 

The main goal of the project was to simplify the existing production and documentation processes and modernize the user interface (HMI).

The project included hardware preparation, module communication, Flutter-based UI development, localization support, configuration handling, and integration of multiple measurement and control modules. 

**Focus:** Raspberry Pi, Flutter, Dart, UART, TWI/I2C, embedded integration, UI/backend separation.

### Automated 360° Object Testing Platform

Development of an embedded control system for an automated test station used to examine objects from multiple angles using cameras.

The system automates object positioning and environmental functions, including motorized rotation, lighting, ventilation, temperature monitoring, and safety mechanisms. The embedded controller communicates with a PC application via USB and coordinates the individual functions of the test station.

**Focus:** ESP32-C3, C/C++, USB CDC, motor control, sensors, hardware integration, prototype development.

### SpO₂ Measurement Algorithm

Development and validation of an SpO₂ measurement algorithm for a medical exercise device.

The work included raw signal acquisition, signal processing, calibration, testing with a reference simulator, data analysis, and implementation of the final algorithm on an embedded system.

**Focus:** C/C++, signal processing, calibration, measurement systems, medical devices.

### Bioimpedance measurement device

Embedded software development and integration for a bioimpedance measurement device, a core components of medical system.

The work included maintaining and extending inherited firmware, implementing device-side functionality, communication with an external application, testing prototypes, investigating hardware/software interaction problems, and preparing the device for further testing.

**Focus:** C/C++, nRF52, embedded firmware, signal acquisition, communication, debugging, hardware/software integration.

## Engineering approach

I enjoy working on practical engineering problems where software and hardware have to work together.

When working with a new system, I typically start by understanding the hardware and communication interfaces, bring individual components up one at a time, verify their behaviour, and then integrate them into the larger system. I rely heavily on measurements, documentation, datasheets, debugging tools, and systematic testing when investigating problems.

Many of the projects I have worked on involved technologies or components that were new to me. I find this part of engineering particularly interesting — learning an unfamiliar technology and gradually turning it into a working solution.
